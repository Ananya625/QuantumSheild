TLS 1.3 Key Exchange (1-RTT) Visualizer
1. TCP Three-Way Handshake
TCP SYN -> SYN/ACK -> ACK established on port 5000.
2. Client Hello (Key Share Offer)
Client sends TLS version (1.3), cipher suites, and ECDH public key share.
3. Server Hello (Key Share Selected)
Server selects cipher suite & key share. Both compute the Shared Secret.
4. Server Certificate & Finished (Encrypted)
Server transmits encrypted certificate, signature verify, and Finished MAC.
5. Client Finished & Channel Secured
Client verifies server signature and replies Finished. Symmetric session active.
